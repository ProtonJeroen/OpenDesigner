# Phase 9D.6 — exact planar preview crash

## Original evidence

Native reader input: private `crash03112026.odc`, SHA-256
`9aec713fa3f46925e6e2a13c516b4bbe71c86b0a37f22d42fc61547a7dad61c4`.
The file is unchanged and is not a committed fixture.

There is one valid closed solid, Part `slot-4` / `Unite 5`, with nine faces:
stock bounds `(0,0,0)` to `(163,80,60)`, an R17 through-hole at `(54,36)`,
and an R18 boss at `(158,36)` spanning z=60..115, clipped by x=163.
The right-end face (native exploration index 5) is a single plane with outward
normal +X, comprising the stock end and the boss's flat cut. Tests select it by
current geometry, never by this incidental index or primitive metadata.

The November 3, 2026 coredump (PID 15740, 21:09:44 CET) shows:

```
CadViewport::mouseMoveEvent
CadViewport::previewMoveFace
MoveFaceGeometry::move
BRepOffset_MakeOffset::MakeOffsetShape
BRepOffset_MakeOffset::BuildOffsetByInter / IntersectEdges
BRepOffset_Inter2d::ConnexIntByInt / RefEdgeInter

```

An isolated GDB process using the actual native document at `649a5eb` reproduces
the same SIGSEGV at **+5 mm**. Offsets 0.1, 0.5, 1 and 2 mm return ordinary
kernel failures first. A C++ exception handler cannot handle this native signal.
The constant-section local planar path refuses this target because its cylinder
axis is perpendicular to the movement normal: its circular trim must change.
Furthermore, that path was dispatched after the crashing global offset call.
Earlier side-plane regressions did not exercise this merged cut face.

## Correction and certificates

Dispatch certified local reconstruction before the OCCT offset builder. Add a
bounded reconstruction for an outward planar cut through one cylindrical boss:

- Analyze the selected plane's current neighborhood and one connected mantle,
  bounded by that cut plane and two perpendicular axial planes. Verify outward
  boss material orientation and exact finite-cylinder/halfspace occupancy.
- Remove that certified boss material and require a valid healed support solid
  whose reunion with the old clipped cylinder equals the original Part.
- Move the actual healed planar patch using the existing local planar API.
  This does not regenerate stock or require a globally rectangular solid.
- Intersect the unchanged finite cylinder with the moved original cut plane and
  reunite it with the moved support. Radius, axis and axial end planes stay fixed.
  Once the plane is beyond the cylinder, preserve the full cylinder directly,
  including at tangency; avoid a needless tangent Boolean intersection.
- Certify independent stock/boss material partitions, outside-region material,
  unaffected trimmed surfaces, one closed manifold solid, surviving moved plane
  and allowed analytic supports. Splits, merges and disappearing boss cut patches
  are legitimate. Unrelated hole and stock material remain protected.

If local reconstruction cannot be certified, inspect the selected connected
planar neighborhood, including coplanar seams. A transverse cylindrical contact
must refuse with diagnostics before any global offset fallback. This is a
face-level guard; other supported planes on the Part remain editable. No signal
handler, primitive flag, persisted feature history or UI disable is introduced.

## Regression and limits

`move-face-crash03112026` runs alone in its own CTest process. Its portable fixture
is an analytic equivalent normalized to the actual nine-face topology, saved and
loaded through native storage in a temporary directory. The optional CLI path
replays the private original file directly:

```
build/OpenDesignerMoveFaceTests --crash-planar /absolute/path/crash03112026.odc
```

Checks cover outward offsets 0.1, 1, 2, 5, 10, 12.9, 13, 13.1, 20 and 40 mm,
independent analytic volumes/material classification and Boolean material oracles,
manifold/solid validity, unchanged source/file bytes, an actual arrow drag near
5 mm, visible live preview, invalid-preview recovery, Cancel, preview/commit
agreement, cached Undo/Redo and another edit after confirmation.

The added changing-section class supports one boss clipped by one radial plane
and outward motion. Inward movement, multiple interacting clipped cylinders,
several radial clip planes, sloped/freeform neighbors and unprovable closure are
refused safely. This does not claim unrestricted planar reconstruction or remove
existing geometric budgets and material checks.
